# Wendy's Price Index 2026

This repository is the open dataset behind the Wendy's Price Index 2026 study.

## About the study

The study covers 26 core menu items in 50 U.S. cities, with one restaurant per city. Prices were collected Oct 20-22, 2026, from order.wendys.com, for a total of 1,300 menu prices.

## Headline findings

- Cheapest basket: Columbus, OH — $114.76
- Priciest basket: Los Angeles — $154.66
- Gap: about 35% between the cheapest and priciest baskets

## Full study and source

- Full study: https://wendyssmenuprices.com/wendys-price-index-2026/
- Source site: https://wendyssmenuprices.com/

## Dataset

The full dataset is available in [observations-v1.csv](observations-v1.csv) in this repository (1,300 prices, 26 items, 50 cities, Oct 20-22, 2026).
